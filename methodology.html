How It Works

Baseline, comparison, persistence, evidence, review.

Neraium’s methodology is designed to preserve context and uncertainty rather than converting telemetry into unsupported certainty.

1. Approved telemetry

Use approved exports or read-only sources supplied for a defined system.

2. Validated baseline

Establish a historical period whose modes and context are suitable for comparison.

3. Later period

Compare subsequent behavior under comparable operating conditions where possible.

4. Persistent changes

Flag relationship changes that remain beyond transient noise.

5. Evidence Package

Organize finding, context, support, limitations, confidence notes, and starting point.

6. Human review

Engineers and maintenance teams decide what the evidence means operationally.

Uncertainty stays visible

Evidence Packages can state that data quality is insufficient, context is incomplete, or the telemetry cannot distinguish between plausible mechanical explanations.

Review is authoritative

The method supports investigation. It does not autonomously diagnose, guarantee lead time, or assign root cause.
