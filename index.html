Operational problem

Important changes can appear before a threshold alarm makes them obvious.

A reading can stay inside limits while its relationship to load, pressure, temperature, command, or output changes persistently.

Traditional monitoring asks

Did this measurement exceed a threshold?

Neraium asks

Has the system behavior persistently changed, and what evidence supports that conclusion?

What Neraium does

Three ways evidence gets organized.

Persistent Behavioral Changes

Find durable changes across comparable operating periods instead of reacting to isolated spikes.

Operating Context

Attach available load, mode, schedule, weather, staging, and maintenance context to each finding.

Evidence Packages

Package the finding, support, and limitations so engineering teams can review it quickly.
