Platform

Read-only infrastructure intelligence for relationship-level review.

Neraium organizes approved operational telemetry into baselines, comparisons, persistent behavior-change findings, and Evidence Packages for human review.

Architecture boundary

The platform is designed to sit outside the control path. For a Historical Evaluation, a secure file export can be enough. Any live source access must be approved, read-only, and deployment-specific.

Approved data in

Exports or approved read-only sources can come from BAS, SCADA, historian, PLC-derived telemetry, databases, APIs, or secure files when those paths are available.

Analysis workspace

Signals are mapped to systems, modes, and operating context before comparing baseline behavior with a later period.

Evidence out

Supported findings are assembled into Evidence Packages for engineers and maintenance teams. Insufficient evidence remains an acceptable result.

Capabilities

  • Relationship evaluation across related signals.
  • Baseline and later-period comparison.
  • Persistence checks to reduce transient-noise findings.
  • Operating Context where data supports it.
  • Evidence Limitations preserved with every example finding.

Not control software

Neraium does not change setpoints, issue commands, override equipment, or replace engineering judgment. It is evidence support for investigation.

Evidence Package example

A concise engineering artifact, not a decorative dashboard.

Illustrative chilled-water pumping example. This is not customer data and it does not assert a diagnosis.

EP-CHW-017

Pump power and delivered flow relationship weakened under comparable operating conditions.

Illustrative only
System
Chilled-water secondary pumping loop.
Behavioral Finding
Pump power increased relative to delivered flow and persisted across comparable operating periods.
Earliest Supported
Example timestamp: 2026-05-14 02:10 local, based on available telemetry.
Operating Context
Comparable load band, same operating mode, similar commanded speed range.
Supporting Evidence
Power-flow residual shift, pressure-flow response change, repeated across illustrative operating windows.
Confidence notes
Persistence: strong. Context match: moderate. Instrument agreement: partial. Explanation certainty: unknown.
Evidence Limitations
Telemetry cannot distinguish hydraulic restriction from pump-performance degradation.
Recommended Starting Point
Verify valve position, inspect strainer differential pressure, and confirm commanded speed matches actual speed.
