Security and Deployment

Read-only by design and outside the control path.

Neraium is designed for conservative OT and enterprise review: approved data paths, read-only operation, no command authority, and human engineering review before action.

Architecture path

The reference model keeps analysis separate from control authority and makes customer-approved data handling explicit.

Approved export or read-only sourceCustomer-approved analysis environmentEvidence PackageHuman engineering review

Implemented

Read-only operation, outside the control path, data minimization for public forms, and no request for telemetry, credentials, diagrams, guest, payment, gaming, surveillance, or reservation data through the public contact form.

Deployment-dependent

Customer-approved data paths, deployment boundary, encryption configuration, auditability where implemented, isolation, retention, and customer-controlled infrastructure depend on the selected architecture.

Planned or assessed separately

Independent security assessments, formal compliance controls, and customer-specific audits are handled as planned or separately assessed controls unless documented for a deployment.

Not claimed

Neraium does not claim SOC 2, formal certifications not held, control-system command authority, autonomous diagnosis, root-cause certainty, guaranteed savings, or guaranteed downtime avoidance.
