Security

Security model and claim-status boundaries.

Neraium is positioned outside the control path and should be deployed in a way that fits customer OT and enterprise segmentation policies.

Implemented public-site controls

The inquiry form asks only for practical scoping fields, includes a honeypot, validates required fields, and provides mailto fallback. It does not request telemetry, credentials, diagrams, or confidential operational information.

Deployment-dependent controls

Read-only source access, encryption, isolation, customer-controlled hosting, audit logging, and single-tenant operation must be confirmed in the selected deployment architecture before being represented as implemented.

Not claimed

No SOC 2 certification, formal compliance certification, autonomous control, root-cause certainty, guaranteed savings, or guaranteed avoided downtime is claimed on this site.

Data minimization

Neraium does not require guest, payment, gaming, surveillance, or reservation data for the infrastructure use cases described here.

Segmentation fit

Evaluation can begin with file export. Live read-only access, if pursued, should be reviewed through the customer’s OT and enterprise security process.
